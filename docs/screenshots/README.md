# Screenshots

Drop screenshots here and reference them from the main `README.md` like:

```markdown
![viewer with multiple agents](docs/screenshots/viewer.png)
```

Suggested file names (to keep the main README's links stable):

- `viewer.png` — main viewer page with agent tabs and segments
- `viewer-edit-mode.png` — edit mode showing per-agent controls
- `trip-example.png` — one rich segment with thought + media
- `setup.png` — `start.bat` running, finding ComfyUI
- `play-all.png` — Play All overlay with a video playing

PNG or JPG both work. Keep individual files under ~1 MB if you can — large images
inflate the repo.
